# linkSharing

**Purpose:** block pastebins, anonymous text/markdown dumps, shareable online notepads and link-dump pages (justpaste.it, pastebin, paste.ee, hastebin, ghostbin, rentry, controlc, pastelink, privatebin, telegra.ph, ...). General URL shorteners are intentionally **not** included.

**Entries:** 281 (119 original + 162 added in the 2026-11-02 expansion)

## Exclusions
- Code playgrounds / dev platforms / path-only pastebins: jsfiddle, jsbin, codepen, ideone, codeshare.io, dotnetfiddle, jsitor, codebeautify, repl.it, gist.github.com, gitlab.com, invent.kde.org, toptal.com, geeksforgeeks, defuse.ca, everfall.com, geany.org, primenotepad.com, snipplr, phpfiddle, quickhighlighter.
- Repurposed: heypasteit.com (sports news), pastefs.com (gambling), pastecn.com (shadcn registry), dochost.io (HTML host), textsnip.com. easypaste.org is now a file uploader → moved to fileSharing.
- NXDOMAIN: dumpz.org, macrobin.co, paste.fo, paste.mod.gg, paste.mozilla.org, pastebin.mozilla.org, paste.ofcode.org, pastebin.icoder.uz, pastecode.fr, pastesqf.com, pst.klgrth.io.
- **Timothy examples:** `paste.ly`, `ren.ly`, `renly.com` = NXDOMAIN; `renly.co` = parked `/lander` page → excluded. "Ren.ly" most likely meant **rentry.co / rentry.org** (both included). justpaste.it + jpst.it included.
